# 实盘下单前检查实施计划

> Execution note: 本轮本地执行，使用隔离 FakeGateway 服务；保留用户当前实盘会话。

**Goal:** 下单前可见阻断原因和保证金估算；实际发送严格复检，确认内容与提交内容一致。

**Architecture:** 引擎提供只读预检查，实际发送复用相同检查。预检查不生成执行意图、不消耗报单频率、不查询柜台、不修改风控基线。网关合约校验在意图生成之前执行；原生网关仍保留校验。前端固定确认参数，预检查失败禁止发送。

**Tech Stack:** FastAPI / Python、Vue 3、pytest / Vitest / Playwright。

- [x] 引擎、API：共享检查、只读基线、保证金与未完成订单检查；测试副作用、状态变化、非法价位。
- [x] 行情时间：拒绝非有限时间戳与明显未来时间戳，覆盖回归。
- [x] 交易面板：只读预检查及刷新、锁定下单与平仓参数、防止确认期间重复请求。
- [x] 隔离浏览器验证确认、阻断、网络失败、过期响应及 2K 布局。
- [x] 完整质量门、README / backlog / 验证记录。

边界：这是本地快照校验，不能替代柜台回报或完整订单对账；保守保证金估算会扣除活跃开仓委托，可能与柜台冻结存在重叠。未知字段不补零。实际 Tick、成交、撤单和重连仍需用户在合适时段验证。本轮不重启实盘、不提交真实交易、不自动提交或推送 Git。
