# 天勤 EDB 历史行情接入

软件通过[天勤官方 EDB 行情历史接口](https://doc.shinnytech.com/edb/latest/md_server.html)下载 CSV，保存到现有 SQLite 历史行情库，供 K 线图和回测共同读取。无需天勤账户、token 或新增 SDK；实际下载沿用软件现有登录会话，数据能力查询不要求登录。没有改变 CTP 前置、账户凭据或实盘委托流程。

## 使用

1. 在 K 线图上方或“回测与分析”页面点击“下载历史行情”。首页和盯盘页内的 K 线图也提供该入口。
2. 选择交易所，输入月份合约，例如 `SHFE` + `au2612`；也可填写完整的 `SHFE.au2612`。郑商所及中金所根码转大写，其余转小写；交易所不匹配、连续合约、指数、期权和非法月份会被拒绝。
3. 选择日线或 1 分钟，填写北京时间的起止日期，点击“下载并保存”。
4. 查看实际返回条数、最早/最晚时间及来源，再点击“查看 K 线”或“用于回测”。下载本身不会切换交易合约或运行策略。
5. 回测自动填入导入结果的合约、周期和实际日期，并关闭模拟数据选项。合约乘数、手续费、保证金仍由用户核对；EDB 价量数据不提供这些账户交易条件。

导入会更新本地相同合约、周期和时间的行。重复下载不产生重复行，不删除范围外的历史；之前的其他来源记录仍保留其来源，混合结果显示 `mixed`。空结果、权限拒绝、网络故障和校验失败均不会补造行情。

## 数据范围与本软件限制

| 项目 | 规则 |
|---|---|
| 免费范围 | 官方允许日线任意历史区间、最近一年的 1 分钟线免鉴权访问；历史预计自 2021-01-01 起，实际以合约上市及数据可得为准 |
| 周期 | 本轮只导入接口原生的 `1d`、`1m`；未新增 5 分钟等周期聚合 |
| 合约 | SHFE、DCE、CZCE、CFFEX、INE、GFEX 月份期货，包括历史月份；不把已到期合约加入可交易目录 |
| 单次范围 | 软件将分钟下载限制为 31 个自然日，日线限制为 3660 个自然日，可分段导入；这是本软件的资源保护限制 |
| 最近日期 | 截止北京时间昨日，避免使用当日尚未结束的 bar；不保证服务已更新到昨日 |
| 时间口径 | 纳秒时间戳以整数解析、转换到 Asia/Shanghai 存储；日线保留供应方交易日标记，不把夜盘按自然日重新拼日线；分钟查询按自然日期筛选，跨夜完整交易日可能需要多取相邻日期 |
| 资源边界 | 每个服务实例最多同时一个下载；响应最多 16 MiB、50000 行；网络读超时 15 秒，另有下载耗时检查；不会自动循环重试 |
| 回测范围 | 原有单次 10000 根 bar 上限保持，超过时页面提示缩短回测日期 |
| 来源 | 每行标记 `tianqin_edb`，保留导入时间；导入审计保存请求范围、实际范围、条数及 CSV SHA-256，不涉及账号密码 |

CSV 会检查列结构、时间范围与粒度、重复时间、有限数值、OHLC 关系、成交量和持仓量。先验证全部返回内容，再写入数据库；明确 HTTP 错误、HTTP 200 的错误文本、损坏数据和可检测的传输截断均拒绝入库。

## 接口及运行隔离

- `GET /data/history/edb`：服务能力、免费分钟起点和软件日期限制。
- `POST /data/history/edb/import`：登录后下载。JSON 字段为 `exchange`、`symbol`、`timeframe`、`start_date`、`end_date`。成功返回 `status=imported`，空数据为 `status=empty`；不会用 200 空对象伪装成功。
- 数据写入现有 `DataManager` / `DatabaseManager`，`/watch/kline`、`/backtest/run` 继续使用同一历史库。
- 下载在工作线程中执行，不持有交易账户操作锁。其操作范围仅为公共价量历史；请求开始时验证本地会话，注销不会中途取消已经接受的历史下载。同期重复下载返回 409。
- 交易报撤单、账户切换、恢复等端点的原有账户锁及授权规则保持不变。

## 验证和加载

真实联网抽查使用黄金 `SHFE.au2612`：2026-02-02 至 02-06 返回并保存 5 根日线；2026-10-15 返回并保存 555 根分钟线。数据仅写入临时隔离数据库，未写入正在运行的实盘历史库，也未连接柜台。摘要及 CSV 校验值见 [live-http.json](evidence/edb-20261019/live-http.json)。这证明本机能连接官方 EDB 并完成转换、入库，不等于已逐笔与交易所行情交叉认证。

自动化测试使用 CSV 固定样本和 FakeGateway，浏览器测试通过真实 API、解析及 SQLite，外部 EDB 传输由隔离服务器替换。浏览器截图中的价格是测试样本，不是上述真实下载数据。完整验证输出见 [验证目录](evidence/edb-20261019/README.md)。

本轮部署检查中，8000 和 5174 端口均未监听。前后端后台启动两次被自动审批以 `blocked by policy` 拒绝，第二次是在用户重新明确授权后重试；工具没有给出更具体的原因。因此本地实盘服务尚未启动，不能把隔离环境测试视为已在实盘页面加载。

在本机两个 PowerShell 终端分别运行：

```powershell
& 'D:\mine\quant\back_end\start-live.bat'
```

```powershell
npm --prefix 'D:\mine\quant\front_end' run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

启动后在 `http://127.0.0.1:5174/login` 输入账户密码，随后从 K 线图或回测页使用下载入口。密码只在本地页面输入。前端遇到旧后端会明确提示 EDB 接口尚未加载。没有新增依赖或环境变量，不需要提供天勤密码。
