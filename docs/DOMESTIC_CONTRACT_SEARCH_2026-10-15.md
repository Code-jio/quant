# 国内期货合约搜索

用户选择国内全部期货品种。此前柜台返回 `AF2610` 等澳元兑美元合约，交易所字段为 `CFFEX`，产品类型为 `FUTURES`，原搜索代码将其直接展示。官方教学资料曾将 AF 定义为澳元兑美元仿真期货，参见[中金所学院题库第 143 页](https://www.e-cffex.com.cn/u/cms/www/202309/281603599mrh.pdf#page=143)。此证据提示柜台目录包含仿真品种，不独立证明账户的真实资金环境。

## 展示规则

- 交易所限定 SHFE、DCE、CZCE、CFFEX、INE、GFEX；柜台产品类型必须为 `FUTURES`。
- 合约必须为品种代码和月份，月份 01—12；排除期权、组合、连续代码及显式不可交易记录。
- CFFEX 限定 IF、IH、IC、IM、T、TF、TS、TL，以免外汇仿真品种混入。中金所新增正式期货品种时，需同步维护 `shared/domestic_futures_policy.json`。
- 商品期货以国内交易所及柜台期货类型为准，不使用可能过时的全品种白名单；新上市商品无需等待本地名称目录更新。缺少中文映射时保留柜台名称，不编造名称或规格。
- 后端先筛选再应用 `limit`，防止期权耗尽搜索名额。中文、代码、拼音首字母及交易所过滤保留；柜台名称只有代码时补充本地已有品种名称。
- 前端 API 客户端再次过滤，覆盖交易台搜索和委托下拉框；收藏及最近查看仅展示符合范围的记录。旧记录不会被自动删除，缺少产品类型的旧收藏需从搜索重新添加以补齐元数据。
- 未连接或尚未取得柜台目录时返回空列表，不以历史数据库替代可选交易合约。目录最多显示 60 条，可进一步按关键词或交易所筛选。

这些是搜索范围规则，不是交易所上市状态认证、账户权限验证或实盘环境鉴定。原生适配器未提供的生命周期字段仍保持未知；下单继续执行已有连接、规格、资金、保证金与风控检查。
