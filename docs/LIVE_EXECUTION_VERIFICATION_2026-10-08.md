## 复现并修复的撤单问题

已安装的 `vnpy_ctp 6.7.11.4` 中，`CtpTdApi.cancel_order` 调用 `reqOrderAction` 后丢弃即时返回码。项目网关随后返回 `True`，因此本地发送失败也会向 API 调用者报告请求成功。

在完全隔离的原生包测试中，将原生发送方法替换为捕获函数，分别返回 -1、-2、-3；三个用例均复现漏报。修复在既有 `ctp_observer.install_observer` 中包装 `reqOrderAction`，非零结果同步抛出错误，使单笔撤单 API 返回失败，批量撤单计入 failed。没有增加交易重试，也没有自行修改订单终态。

返回 0 仍只表示请求发出；订单必须收到柜台 `onRtnOrder` 的撤单状态才变为 cancelled。异步撤单拒绝保留活跃订单，并保留原生错误日志。
